## LO QUE NECESITO

Crea un componente React (o actualiza mi componente existente) que muestre los resultados del análisis de marca con las siguientes secciones:

### 1. HEADER CON RESUMEN
- Nombre de la marca grande y destacado
- Badge de viabilidad con colores:
  - ALTA = verde
  - MEDIA = amarillo/naranja
  - BAJA = rojo
- Si hay alerta crítica, mostrar un banner de advertencia

### 2. SECCIÓN: ANÁLISIS DE VIABILIDAD
- Mostrar el nivel de viabilidad con un indicador visual (semáforo o barra)
- Mostrar la alerta crítica si existe
- Mostrar el análisis de riesgo en un card
- Si requiere_verificacion_impi es true, mostrar nota: "Se recomienda verificar disponibilidad en IMPI"

### 3. SECCIÓN: CLASIFICACIÓN NIZA
- Card principal con la clase principal:
  - Número de clase grande
  - Nombre de la clase
  - Descripción jurídica (formato legible, no todo en mayúsculas)
- Cards secundarios para cada clase adicional (solo si existen):
  - Mostrar clases 1-5 en un grid
  - Cada card con número, nombre y descripción
- Mostrar "Total de clases para protección: X"

### 4. SECCIÓN: RECOMENDACIÓN DEL EXPERTO
- Card destacado con el texto de recomendacion_experta
- Mostrar siguiente_paso como call-to-action

### 5. SECCIÓN: ALTERNATIVAS DE NOMBRE (solo si viabilidad es MEDIA o BAJA)
- Parsear sugerencias_nombres (es un JSON string)
- Mostrar cada alternativa como un chip/badge clickeable

### 6. BOTONES DE ACCIÓN
- "Continuar con registro" (clase principal)
- "Protección Total (X clases)" - si hay clases secundarias
- "Descargar análisis PDF"

## ESTILOS
- Usar Tailwind CSS
- Colores profesionales (azul oscuro, blanco, acentos verdes/rojos)
- Cards con sombras suaves
- Tipografía clara y legible
- Mobile-first responsive
